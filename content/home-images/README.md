# Kezdőlapi seed-képek

Ezek a fájlok a kezdőlap seedjének és az induláskori média-helyreállításnak
(`src/lib/home-seed.ts`, `src/lib/media-restore.ts`) a forrásai.

A szerkesztők a képeket a Payload admin Médiatárában cserélik. A seed és a
helyreállítás meglévő média-rekordot nem ír felül: új feltöltés csak akkor
történik, ha a rekord vagy a fájl hiányzik.

Titkot, jelszót, tokent ide ne tegyél.
